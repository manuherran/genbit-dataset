El dataset de Genbit

Todo lo que hace Genbit queda registrado: tripulación, clientes de todo el sistema solar, proyectos de genética y física cuántica, productos, pedidos, pagos y devoluciones. Aquí tienes ese registro como base de datos relacional para aprender SQL, análisis de datos o machine learning.
